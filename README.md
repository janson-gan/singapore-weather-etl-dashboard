# Singapore Weather ETL Pipeline and Dashboard

## Project Overview
This project builds a simple end to end ETL pipeline using Singapore rainfall and temperature data. The pipeline extracts raw weather data, clean and transforms it using Python, validates the data for quality issues, loads the cleaned data into PostgreSQL, and create a Power BI dashboard to analyse rainfall and temperature trends.

## Tools Used
- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- GitHub

## Data Source
- Singapore rainfall data
- Singapore temperature data

## ETL Workflow
1. Extract rainfall and temperature data from public sources.
2. Clean and transform the raw data using Python and Pandas
3. Validate the data for missing values, duplicates, and invalid readings.
4. Load the cleaned data into postgreSQL.
5. Use SQL and Power BI to analyse the rainfall and temperature trends.
